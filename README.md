# Velour & Brew
Run locally: `npm install` then `npm run dev` (build: `npm run build`).
Edit business details, WhatsApp number (digits with country code, e.g. 923001234567) and testimonials in `src/data/siteConfig.js`; menu in `src/data/products.js`.
Contact form: wire a real service in `submitContactForm()` in `src/components/ContactForm.jsx`.
Images are remote Unsplash photos with built-in fallbacks; swap URLs for your own photography before launch.
